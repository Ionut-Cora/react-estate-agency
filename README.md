# Percival Estate Agency

## Description
A polished, multi-page real estate interface built with [React JS](https://react.dev/) and [Material UI](https://mui.com/). This template includes seven pages, including dedicated views for rentals and sales, and integrates key UI components such as a carousel, mortgage calculator, and dynamic navigation. The project emphasizes a clean architecture, responsive layout, and industry-specific features tailored to real estate platforms.

## View live website: https://ionut-cora.github.io/react-estate-agency/

## Dependencies
- [React JS](https://react.dev/) - JavaScript library
